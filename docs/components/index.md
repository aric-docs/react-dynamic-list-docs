# Components

React Dynamic List provides a declarative component and an imperative hook that share the same underlying store.

| API                                              | Type      | Description                                   |
| ------------------------------------------------ | --------- | --------------------------------------------- |
| [`<DynamicList>`](/components/dynamic-list)      | Component | Declarative wrapper with slot-based rendering |
| [`useListContext`](/components/use-list-context) | Hook      | Imperative access to list operations          |
| [Store & Events](/components/store-utilities)    | Utilities | Direct store access and event subscription    |
